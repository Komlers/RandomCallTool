随机抽组操作指南

随机抽组功能支持从数字（1-26）或字母（A-Z）中随机抽取指定数量的组，适用于分组、编号抽取等场景。

操作步骤

① 切换至随机抽组模式

打开程序后，切换到「随机抽取」选项卡，选择「随机抽组」模式。

② 选择分组方式

  • 数字（123）：组编号为 1, 2, 3 ... 26
  • 字母（ABC）：组编号为 A, B, C ... Z

③ 设置参数

  • 样本总数：设置总组数，范围 1-26
  • 抽取数量：设置要抽取的组数（不能超过总组数）

④ 执行抽取

点击「抽取」按钮或按 Ctrl+Enter 进行随机抽取。抽取结果会立即展示在程序窗口中。

⑤ 保存结果

抽取完成后，可以按 Ctrl+S 将本次结果保存为 HTML 文件，或按 Ctrl+Shift+S 批量保存所有历史记录。

示例场景

  • 课堂分组：将全班同学随机分到 A、B、C、D 四个组
  • 编号抽选：从 1-20 号中随机抽取 5 个号码
  • 轮值排班：从多个小组中随机抽取本周值班组

小贴士

  • 总组数最大为 26（对应字母表 A-Z）
  • 抽取结果支持重复抽取，每次独立随机
  • 配合「智能抽样」模式使用时可降低近期被选中项的权重
