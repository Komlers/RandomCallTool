随机抽人操作指南

随机抽人功能支持从样本文件（.rcp / .txt / .csv）或样本库中随机抽取指定数量的人名。

操作步骤

① 切换至随机抽人模式

切换到「随机抽取」选项卡，选择「随机抽人」模式。

② 加载样本文件

有多种方式加载样本名单：

操作 快捷键 说明
手动选择文件 Ctrl+O 从文件对话框选择 .rcp / .txt / .csv 文件
从样本库加载 Ctrl+Shift+O 从已导入的样本库中快速选择
重新加载当前文件 Ctrl+R 重新读取当前已加载的文件
自动加载默认样本 Ctrl+D 加载配置中预设的默认样本文件

③ 设置抽取参数

  • 抽取数量：设置要抽取的人数（不能超过样本总数）
  • 抽样模式：选择基本 / 智能 / 加权 三种模式之一（详见 抽样模式详解）

④ 执行抽取

点击「抽取」按钮或按 Ctrl+Enter 进行随机抽取。结果会展示在程序窗口右侧的历史记录面板中。

⑤ 结果管理

  • Ctrl+S — 保存最新一条抽取结果
  • Ctrl+Shift+S — 批量保存所有历史记录
  • Ctrl+W — 清除所有历史记录
  • 结果文件默认为 HTML 格式，保存位置可在配置中设置

支持的样本文件格式

格式 说明 推荐
.rcp 经 Base64/Hex 编码的名单文件 ⭐ 推荐
.txt 纯文本文件，每行一个名字
.csv 逗号分隔值文件
