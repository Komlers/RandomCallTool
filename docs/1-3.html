悬浮球与桌面集成

桌面悬浮球、系统托盘与开机自启都在「配置 → 桌面集成」中管理，本页集中说明。

桌面悬浮球

启用后，桌面上会出现一个半透明的圆形按钮并始终置顶显示，方便在不切换窗口的情况下快速抽取。

① 左键单击

左键单击悬浮球，会立即执行当前选定的操作（默认是抽 1 个人），结果与主界面抽取完全一致：同样会写入历史记录、按「配置 → 提醒」的设置提醒，并按需自动保存结果。

② 右键菜单

右键单击悬浮球打开菜单，用来预设下一次左键单击要执行的操作：

菜单项说明
抽取模式 ▸选择左键要执行的抽取方式：抽字母组（A、B、C…）/ 抽数字组（1、2、3…）/ 抽人（已加载的名单）
抽取数量 ▸选择每次抽取 1~9 个（数量上限会根据当前模式实际可抽数量自动调整）
悬浮球大小 ▸在小 / 中 / 大三档之间切换

三个子菜单都是单选，当前生效的预设会带勾选标记。例如当预设为「抽人 + 抽 3 个」时，「抽取模式」里的「抽人」和「抽取数量」里的「抽 3 个」都会显示勾选。

设定后，之后每次左键单击都会按该预设执行，直到再次修改。

③ 拖动位置与调节大小

按住悬浮球拖动即可移动位置，程序会自动记住拖动后的位置，下次启动仍会出现在该处。拖动不会触发抽取，只有「原地单击」才会执行。

大小共三档（小 / 中 / 大，默认为「中」），既可在右键菜单的「悬浮球大小」中快速切换，也可在「配置 → 桌面集成 → 悬浮球大小」中设置，两处互相同步。

抽组的组数取自「配置 → 抽样设置 → 默认值设定 → 抽组默认总数」，与主界面保持一致。

系统托盘

托盘功能让程序在关闭主窗口后仍可继续在后台运行，随时从任务栏通知区唤回。

① 关闭窗口后保留系统托盘

勾选后，点击主窗口右上角的关闭按钮不会退出程序，而是把主界面隐藏到托盘继续运行；再次双击托盘图标（或使用托盘菜单「显示主界面」）即可唤回。

取消勾选后，程序不再驻留托盘 —— 此时任何退出操作都会完全退出程序，不会出现窗口消失但程序仍在后台的情况。

② 启动后直接后台驻留托盘

勾选后，程序启动时不会显示主界面，而是直接在托盘中静默运行，适合配合开机自启使用。

③ 托盘右键菜单

菜单项功能
显示主界面显示并前置主窗口
软件配置显示主窗口并打开配置窗口
检测更新启动独立更新程序
显示悬浮球切换桌面悬浮球的显示 / 隐藏（带勾选标记）
退出完全退出程序（同时关闭悬浮球与托盘）

开机自启

在「配置 → 桌面集成」勾选「开机自启」后，开机登录 Windows 时会自动启动主程序。

  • 原理：把开始菜单中的主程序快捷方式（随机抽取工具.lnk）复制到系统公共启动文件夹（在资源管理器地址栏输入 shell:common startup 即可打开）；取消勾选则删除该快捷方式
  • 公共启动文件夹为所有用户共有，普通账户没有写入权限，勾选或取消时会弹出 UAC 提权请求，允许后才能完成设置；若拒绝提权则本次设置中止
  • 勾选框的初始状态以启动文件夹中快捷方式是否实际存在为准
  • 该功能仅支持 Windows

注意事项

  • 主界面的「退出」按钮会完全退出程序（包括托盘与悬浮球），因此点击后会弹出确认提示。
  • 托盘与悬浮球依赖 pystray 与 Pillow。未安装时托盘不可用，程序会自动改为「关闭窗口即询问是否退出」。
  • 若在运行中关闭了托盘功能，程序会自动把主界面显示回来，避免窗口被隐藏后无法唤出。
