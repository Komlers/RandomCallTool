软件配置详细详解

通过菜单栏「编辑 → 配置」（Ctrl+,）或主页「设置」按钮打开多选项卡配置窗口，以下按选项卡逐项详解。

基本设置

  • 自动保存抽取结果：
    抽取完成后是否自动保存结果文件
  • 结果保存位置：
    选择结果保存到「数据目录」或「桌面」
  • 启动时自动加载样本（随机抽人）：
    启动时是否自动加载随机抽人的默认样本
  • 启动时自动加载名单（随机点名）：
    点名名单的自动加载开关，与随机抽人相互独立
  • 加载样本时自动合并重复名字：
    加载名单时是否自动去除重复项
  • 历史记录条数：
    设置历史记录面板保留的最大条数（5~30）
  • 把抽取历史实时写入本地文件：
    每次抽取追加一行到 data/history/YYYY-MM-DD.txt（按日期分文件），并用旁边的「打开记录目录」按钮快速访问
  • 默认加载样本：
    选择启动时自动加载的样本库文件

抽样设置

  • 抽样模式：
    选择默认的抽样模式（基本 / 智能 / 高级）
  • 智能模式使用固定权重：
    勾选后可在智能模式下自定义权重
  • 高级抽取配置：
    打开高级抽取配置窗口，设置放回/不放回、抽取优化、加权等详细选项
  • 随机点名配置：
    打开随机点名设置窗口，设置点名速率、打乱名单、放回/不放回、重置限度等
  • 默认值设定：
    默认抽取方式（抽人 / 抽组）、抽组默认总数、默认选取数量

样本管理

  • 查看已保存的样本库条目（显示名称与文件大小），样本库上限 50 个
  • 「导入样本」添加新样本，「打开样本目录」直接打开样本存放目录
  • 对单条样本可执行重命名、删除，以及导出为 TXT / RCP

提醒

  • 提醒方式：
    选择随机抽取完成后的提醒方式（随机点名不触发提醒）
    • 弹窗提醒：
      弹出结果窗口（默认）
    • ClassIsland 通知：
      通过 IslandMQ 插件把结果推送到教室电脑
  • 主机 IP / 端口：
    教室电脑的地址（默认 127.0.0.1:5555）
  • 通知标题：
    推送内容中的遮罩文本；留空时自动使用「随机抽取结果」
  • 遮罩时长 / 正文时长：
    标题遮罩与正文通知的显示时长（秒，默认 1 秒 / 3 秒）
  • 发送失败时改用弹窗提醒：
    教室电脑不在线时仍能看到结果
  • 连接测试 / 发送测试通知：
    验证与 ClassIsland 的连通性和显示效果

ClassIsland通知 功能，需要在电脑上安装了 ClassIsland 软件，以及在软件内安装 IslandMQ 插件，并且确保 ClassIsland 软件已启动并运行，否则无法推送通知。

另外，一般情况下无需对 IslandMQ 插件进行额外配置，如果配置有更改，请根据实际情况调整IP和端口。

桌面集成

悬浮球、系统托盘与开机自启的开关集中在此选项卡，各项的详细用法（含右键菜单、UAC 提权等）参见 悬浮球与桌面集成。

更新

  • 版本更新源：
    切换检测更新的源（GitHub / Gitee）
  • 启动时自动检测更新：
    开启/关闭开机自动检测新版本
  • 接收测试版更新：
    开启后版本检测将同时检查测试版更新（默认关闭）

关于版本号与版本代码的含义及其命名规则，参见 版本号命名规则。

配置窗口底部提供「确定 / 应用 / 关闭」三个按钮。关闭时若有未应用的更改，程序会询问是否应用。

命令行参数（初级版）

主程序支持通过命令行参数在启动时直接应用自定义权重，适合脚本、自动化任务或自定义快捷方式调用。

参数说明

参数说明
--weight-set <名字> <权重>设置一条权重，可重复出现；出现该参数即开启自定义权重
-lib <样本库名>仅加载样本库中指定样本时生效，可重复或使用列表
-file <文件名或路径>仅指定外部文件生效；启动时自动加载第一个存在的文件

名称列表

权重名字与 -lib / -file 的目标均支持 JSON 风格列表（整体用单引号包裹，避免与外层引号冲突）：

--weight-set '["测试样本12","测试样本13"]' 20.00

列表内各项使用同一权重；若要为不同名字设置不同权重，重复书写多个 --weight-set。

目标范围

  • 不写 -lib / -file：任何已加载样本中只要存在该名字即设置权重
  • -lib：仅样本库中指定样本被加载时生效
  • -file：
    • 值为纯文件名（如 demo.txt）：任何路径下的同名文件都生效
    • 值带路径（如 D:\demo\demo.txt）：仅该具体文件生效

示例

rctool.exe --weight-set "测试样本12" 20.00
rctool.exe --weight-set "测试样本12" 20.00 -lib "测试样本文件"
rctool.exe --weight-set '["测试样本12","测试样本13"]' 20.00 -file "demo.txt"

参数本身的错误（权重值不是数字、为负数、参数缺值、未知参数等）只写入运行日志，不弹出前端窗口；异常部分忽略，程序正常启动。

如果是在公共电脑上，该功能可能会被滥用，请自行评估使用场景。

退出程序

根据托盘设置的不同，退出行为有所区别：

  • 托盘已启用：点击窗口关闭按钮会隐藏到托盘；主页「退出」按钮、菜单「文件 → 退出」或托盘菜单「退出」则会完全退出程序。
  • 托盘已关闭：所有退出操作（包括关闭窗口）都会完全退出程序，并弹出确认提示。
