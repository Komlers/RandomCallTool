桌面悬浮球与系统托盘

这两项桌面常驻功能都可在「配置 → 桌面集成」中分别开关，默认均为开启。

桌面悬浮球

启用后，桌面上会出现一个半透明的圆形按钮并始终置顶显示，方便在不切换窗口的情况下快速抽取。

① 左键单击

左键单击悬浮球，会立即执行当前选定的操作（默认是抽 1 个人），结果与主界面抽取完全一致：同样会写入历史记录、按「配置 → 提醒」的设置提醒，并按需自动保存结果。

② 右键菜单

右键单击悬浮球打开菜单，用来预设下一次左键单击要执行的操作：

菜单项 说明
抽字母组将左键操作设为从 A、B、C… 中抽组
抽数字组将左键操作设为从 1、2、3… 中抽组
抽人将左键操作设为从已加载的名单中抽人
抽取数量 ▸展开子菜单，选择每次抽取 1~9 个
悬浮球大小 ▸展开子菜单，在小 / 中 / 大三档之间切换（当前档位带勾选标记）

例如：右键选择「抽人」和「抽 3 个」后，之后每次左键单击都会抽取 3 个人，直到再次修改。

③ 拖动位置与调节大小

按住悬浮球拖动即可移动位置，程序会自动记住拖动后的位置，下次启动仍会出现在该处。拖动不会触发抽取，只有「原地单击」才会执行。

大小共三档（小 / 中 / 大，默认为「中」），既可在右键菜单的「悬浮球大小」中快速切换，也可在「配置 → 桌面集成 → 悬浮球大小」中设置，两处互相同步。

抽组的组数取自「配置 → 抽样设置 → 默认值设定 → 抽组默认总数」，与主界面保持一致。

系统托盘

托盘功能让程序在关闭主窗口后仍可继续在后台运行，随时从任务栏通知区唤回。

① 关闭窗口后保留系统托盘

勾选后，点击主窗口右上角的关闭按钮不会退出程序，而是把主界面隐藏到托盘继续运行；再次双击托盘图标（或使用托盘菜单「显示主界面」）即可唤回。

取消勾选后，程序不再驻留托盘 —— 此时任何退出操作都会完全退出程序，不会出现窗口消失但程序仍在后台的情况。

② 启动后直接后台驻留托盘

勾选后，程序启动时不会显示主界面，而是直接在托盘中静默运行，适合开机自启等场景。

③ 托盘右键菜单

菜单项 功能
显示主界面显示并前置主窗口
软件配置显示主窗口并打开配置窗口
检测更新启动独立更新程序
显示悬浮球切换桌面悬浮球的显示 / 隐藏（带勾选标记）
退出完全退出程序（同时关闭悬浮球与托盘）

注意事项

  • 主界面的「退出」按钮会完全退出程序（包括托盘与悬浮球），因此点击后会弹出确认提示。
  • 托盘与悬浮球依赖 pystray 与 Pillow。未安装时托盘不可用，程序会自动改为「关闭窗口即询问是否退出」。
  • 若在运行中关闭了托盘功能，程序会自动把主界面显示回来，避免窗口被隐藏后无法唤出。
