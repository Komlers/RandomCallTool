名单编码工具说明

随机抽人名单编码工具（EncodeTool）是 RandomCallTool 的配套工具，版本 v1.2。用于将明文名单编码为 .rcp 文件，供主程序的"随机抽人"功能使用。

支持编码方式：Base64 / Hex（十六进制）。

基本操作

① 输入明文名单

  • 在上方文本框中直接输入名单（每行一个名字）
  • 点击「从文件加载」（Ctrl+O）导入文本文件（自动识别编码）
  • 点击「追加文件」可将另一个文件的内容合并到输入区

② 处理文本（可选）

点击「处理文本」或按 F5 自动处理，可去除重复项、首尾空格、空行、按字母排序等。相关选项可在「配置」中设置。

③ 编码名单

  • 在底部选择编码方式：Base64 或 Hex（十六进制）
  • Ctrl+Enter — 快速编码（仅生成编码文本，不保存文件）
  • Ctrl+S — 编码并保存为 .rcp 文件

④ 输出与保存

  • 编码结果会显示在下方文本框中
  • 点击「复制到剪贴板」复制编码后的文本
  • Ctrl+Shift+S — 将输入区文本保存为明文文件

解码与验证

解码测试

选中输出框中的编码内容，点击「解码测试」或按 Ctrl+D 查看解码结果，工具会自动检测编码方式。

编码/解码循环验证

点击「测试编码/解码循环」可验证编码功能的完整性，确保编码后的数据能正确解码还原。

批量处理

  • 批量编码：通过「文件 → 批量编码」选择目录，批量编码该目录下所有 .txt 文件
  • 批量解码：通过「文件 → 批量解码」对编码文件进行批量解码测试
  • 支持 Base64 / Hex 两种编码方式

命令行用法

编码工具也支持命令行模式：

# 加载指定文件并打开 GUI
encode.exe 名单.txt

# 显示版本信息
encode.exe -v

# 批量编码整个目录（Base64）
encode.exe --batch ./input_dir --output ./output_dir

# 批量编码整个目录（Hex）
encode.exe --batch ./input_dir --output ./output_dir --method hex

快捷键一览

快捷键 功能

Ctrl+S编码并保存
Ctrl+Enter快速编码
Ctrl+D解码测试
Ctrl+W清空输入
Ctrl+Shift+W清空输出
Ctrl+Shift+S保存为明文
F5处理文本
Ctrl+I统计信息
Ctrl+,配置
