更新与卸载工具说明

随机抽取工具套件除主程序 rctool.exe 外，还包含两个独立的小工具：更新程序 update.exe 与 卸载工具 remove.exe。两者均可独立运行，也可由主程序调用。

更新程序（update.exe）

打开方式

  • 主程序主页点击「更新」按钮
  • 菜单「工具 → 检测更新」
  • 配置窗口「更新」选项卡 → 「立即检查更新」
  • 程序启动时自动检测（可在配置中关闭）

更新源

更新程序支持 GitHub 与 Gitee 两个更新源，可在更新程序首页或配置窗口「更新」选项卡中切换：

  • Gitee：中国大陆网络环境推荐
  • GitHub：其他地区推荐

测试版更新

勾选「接收测试版更新」后，版本检测会同时检查测试版（Beta）更新。该选项在主程序配置窗口「更新」选项卡与更新程序首页均可设置。

检测结果

状态 可用操作
发现新版本
  • 直接下载（推荐） — 下载安装包并自动完成更新
  • 前往官网下载 — 在浏览器中打开发布页面
  • 备用下载 — 夸克网盘 / 蓝奏云（蓝奏云会显示访问码）
已是最新版本 显示当前版本与远程版本信息，无需操作

更新前请先关闭「随机抽取工具套件」内的所有程序（主程序、更新程序等），否则可能因文件占用导致安装失败，进而造成程序完整性损坏或数据丢失。

卸载工具（remove.exe）

卸载工具提供三种模式，运行时需先选择模式并二次确认，操作不可撤销。

模式 说明
保留数据 仅删除程序文件，保留数据配置和桌面结果
重置配置 仅删除数据配置和日志，保留程序文件
完全卸载 删除所有文件（包括程序、数据、配置、日志）

额外清理项

除程序目录外，执行「保留数据」或「完全卸载」时，卸载工具还会一并清理以下内容：

  • 开始菜单中的程序组文件夹（「随机抽取工具」/「随机抽取工具套件」，当前用户与所有用户）
  • 桌面快捷方式（当前用户桌面与公共桌面）

卸载前请确保已备份重要数据。程序不会自动备份配置与结果文件。

关于名单编码工具

自 V2.5.2 起，原先配套的「名单编码工具（EncodeTool）」已从套件中移除。日常使用可直接导入 .txt / .csv 名单；如需 .rcp 文件，可将明文名单按 Base64 编码后另存为 .rcp，或先将名单导入样本库，再在「配置 → 样本管理」中导出为 .rcp。
