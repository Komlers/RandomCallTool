独立更新程序

更新程序 update.exe 是套件中独立的小工具，可独立运行，也可由主程序调用，用于检测并更新到新版本。

打开方式

  • 主程序主页点击「更新」按钮
  • 菜单「工具 → 检测更新」
  • 配置窗口「更新」选项卡 → 「立即检查更新」
  • 程序启动时自动检测（可在配置中关闭）

更新源

更新程序支持 GitHub 与 Gitee 两个更新源，可在更新程序首页或配置窗口「更新」选项卡中切换：

  • Gitee：中国大陆网络环境推荐
  • GitHub：其他地区推荐

测试版更新

勾选「接收测试版更新」后，版本检测会同时检查测试版（Beta）更新。该选项在主程序配置窗口「更新」选项卡与更新程序首页均可设置。

界面显示

更新程序各页面采用统一的微软雅黑字阶与卡片式信息排列，主按钮、次要按钮风格统一，进度条配色与整体淡蓝风格一致，检测中页面内容居中显示。

检测结果

状态可用操作
发现新版本
  • 直接下载（推荐） — 下载安装包并自动完成更新
  • 前往官网下载 — 在浏览器中打开发布页面
  • 备用下载 — 夸克网盘 / 蓝奏云（蓝奏云会显示访问码）
已是最新版本 显示当前版本与远程版本信息，无需操作

更新程序实际比较的是版本代码（vercode）而不是版本号文本，其含义与编码规则详见 版本号命名规则。

更新前请先关闭「随机抽取工具套件」内的所有程序（主程序、更新程序等），否则可能因文件占用导致安装失败，进而造成程序完整性损坏或数据丢失。
