配置管理

通过菜单栏「编辑 → 配置」（Ctrl+,）或主页「设置」按钮打开多选项卡配置窗口，包含以下六个选项卡：

基本设置

  • 自动保存抽取结果：抽取完成后自动保存结果文件
  • 结果保存位置：选择结果保存到「数据目录」或「桌面」
  • 启动时自动加载样本（随机抽人）：启动时自动加载默认样本
  • 启动时自动加载名单（随机点名）：点名名单的自动加载开关，与随机抽人相互独立
  • 加载样本时自动合并重复名字：加载名单时自动去除重复项
  • 历史记录条数：设置历史记录面板保留的最大条数（5~30）
  • 把抽取历史实时写入本地文件：每次抽取追加一行到 data/history/YYYY-MM-DD.txt（按日期分文件），并用旁边的「打开记录目录」按钮快速访问
  • 默认加载样本：选择启动时自动加载的样本库文件

抽样设置

  • 抽样模式：选择默认的抽样模式（基本 / 智能 / 高级）
  • 智能模式使用固定权重：勾选后可在智能模式下自定义权重
  • 高级抽取配置：打开高级抽取配置窗口，设置放回/不放回、抽取优化、加权等详细选项
  • 随机点名配置：打开随机点名设置窗口，设置点名速率、打乱名单、放回/不放回、重置限度等
  • 默认值设定：默认抽取方式（抽人 / 抽组）、抽组默认总数、默认选取数量

样本管理

  • 查看已保存的样本库条目（显示名称与文件大小），样本库上限 50 个
  • 「导入样本」添加新样本，「打开样本目录」直接打开样本存放目录
  • 对单条样本可执行重命名、删除，以及导出为 TXT / RCP

提醒

  • 提醒方式：选择随机抽取完成后的提醒方式（随机点名不触发提醒）
    • 弹窗提醒：弹出结果窗口（默认）
    • ClassIsland 通知：通过 IslandMQ 插件把结果推送到教室电脑
  • 主机 IP / 端口：教室电脑的地址（默认 127.0.0.1:5555）
  • 通知标题：推送内容中的遮罩文本；留空时自动使用「随机抽取结果」
  • 遮罩时长 / 正文时长：标题遮罩与正文通知的显示时长（秒，默认 1 秒 / 3 秒）
  • 发送失败时改用弹窗提醒：教室电脑不在线时仍能看到结果
  • 连接测试 / 发送测试通知：验证与 ClassIsland 的连通性和显示效果

桌面集成

集中管理两项桌面常驻功能，详细用法参见 桌面悬浮球与系统托盘。

  • 显示桌面悬浮球：在桌面显示一个可拖动的置顶圆形按钮
    • 左键单击：立即执行当前选定的抽取操作（默认抽 1 个人）
    • 右键菜单：预设左键要执行的操作（抽字母组 / 抽数字组 / 抽人）与抽取数量（1~9 个）
    • 拖动可调整位置，程序会自动记住
    • 悬浮球大小：三档可选（小 / 中 / 大，默认「中」），也可在悬浮球右键菜单中快速切换
  • 关闭窗口后保留系统托盘：关闭主窗口后程序继续在托盘中运行；取消勾选则任何退出操作都会完全退出
  • 启动后直接后台驻留托盘：启动时不显示主界面，直接静默驻留托盘

更新

  • 版本更新源：切换检测更新的源（GitHub / Gitee）
  • 启动时自动检测更新：开启/关闭开机自动检测新版本
  • 接收测试版更新：开启后版本检测将同时检查测试版更新
  • 当前版本信息与「立即检查更新」按钮

关于版本号与版本代码的含义及其命名规则，参见 版本号规则说明。

配置窗口底部提供「确定 / 应用 / 关闭」三个按钮。关闭时若有未应用的更改，程序会询问是否应用。

退出程序

根据托盘设置的不同，退出行为有所区别：

  • 托盘已启用：点击窗口关闭按钮会隐藏到托盘；主页「退出」按钮、菜单「文件 → 退出」或托盘菜单「退出」则会完全退出程序。
  • 托盘已关闭：所有退出操作（包括关闭窗口）都会完全退出程序，并弹出确认提示。
