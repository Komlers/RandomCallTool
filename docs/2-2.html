主程序快捷键

快捷键 功能
Ctrl+O选择样本文件
Ctrl+Shift+O从样本库加载
Ctrl+R重新加载当前文件
Ctrl+D自动加载默认样本
Ctrl+I导入样本到样本库
Ctrl+Enter执行抽取
Ctrl+S保存最新结果
Ctrl+Shift+S批量保存所有历史
Ctrl+W清除所有历史记录
Ctrl+Shift+R重置抽样历史
Ctrl+,打开配置窗口
Ctrl+T切换到随机抽取选项卡
Ctrl+L查看日志文件

配置管理

通过菜单栏「编辑 → 配置」（Ctrl+,）打开多选项卡配置窗口，包含以下设置项：

基本设置

  • 自动保存结果：抽取完成后自动保存结果文件
  • 结果保存位置：选择结果保存到 data/result 目录或桌面
  • 自动加载样本：启动时自动加载预设的默认样本文件
  • 合并重复名字：加载时自动去除样本中的重复项

抽样设置

  • 默认抽样模式：设置启动时的默认抽样模式（基本 / 智能 / 加权）
  • 智能抽样记忆窗口：调整智能抽样的历史追溯次数

样本管理

  • 查看已导入样本库的所有名单
  • 删除不需要的样本库条目
  • 样本库上限：50 个

默认值

  • 默认抽取模式：随机抽组 / 随机抽人
  • 默认抽取数量：设置每次打开时的默认抽取数量
  • 默认组总数：设置随机抽组的默认总组数

更新设置

  • 更新源：切换检测更新的源（GitHub / Gitee）
  • 自动检测更新：开启/关闭启动时自动检测新版本
