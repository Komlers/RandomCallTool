跨平台说明

随机抽取工具基于 Python + tkinter 编写，代码层面考虑了多平台运行，但官方仅提供 Windows 编译版本。

平台支持总览

平台支持情况获取方式
Windows 完整支持并持续测试（Windows 7 / 8 / 8.1 / 10 / 11） 提供安装版与绿色版，开箱即用
Linux 可通过源码运行，源码做了一些小适配，但可能还会有位置的问题 源码运行 / 自行编译
macOS 同上 同上

对于macOS平台，能做的适配可能会更少，因为本程序只在Windows和Linux平台上做过测试，且只在Windows平台上开发。

此外，例如检测更新、卸载软件、开机自启等等功能，只确保Windows能用，Linux和macOS无法使用。

各功能的平台相关性

  • 打开文件 / 目录：已做跨平台处理 —— Windows 使用 os.startfile，macOS 使用 open，Linux 使用 xdg-open
  • 桌面悬浮球 / 系统托盘：基于 pystray 与 Pillow，这两个库本身支持三大平台
  • 开机自启：仅支持 Windows。其实现依赖开始菜单快捷方式与系统启动文件夹（shell:common startup），并通过 UAC 完成提权；非 Windows 下该配置项不可用
  • 更新程序 / 卸载工具：围绕 Windows 的安装方式设计（开始菜单、桌面快捷方式、自解压安装到 C:\Apps\RandomCallTool），未适配其他平台

悬浮球实测在Linux下会有显示问题，表现为圆形外侧有一圈白色边框。

测试环境：Fedora 44 + Wayland + KWin + KDE Plasma 6.7.5

从源码运行

macOS 与 Linux 用户可按以下步骤从源码运行主程序：

  1. 安装 Python 3.8 或更高版本（官方开发与编译使用 Python 3.8.10）；Linux 下还需安装 tkinter，例如 Ubuntu / Debian：sudo apt install python3-tk
  2. 获取源码（GitHub / Gitee）并进入项目目录
  3. 安装依赖：pip install -r requirements.txt
  4. 运行主程序：python src/rctool.py
