常见问题与注意事项

常见问题

Q: 抽取人数超过了样本总数怎么办？

程序会自动限制抽取数量不能超过样本总数。如果您设置的抽取数量大于样本总数，程序会自动将其调整为样本总数的最大值。

Q: 如何将常用名单保存起来，方便下次使用？

您可以将常用名单导入样本库（上限 50 个）。通过菜单「文件 → 导入样本到库」（Ctrl+I）即可将当前加载的名单添加到样本库中。下次使用时，按 Ctrl+Shift+O 从样本库快速加载。

Q: 结果文件保存在哪里？

结果文件默认保存在 data/result 目录，也可以在配置中改为保存到桌面。您可以通过菜单「文件 → 打开结果目录」快速访问保存位置。

Q: 抽取历史记录保存在哪里？

除了界面右侧的历史记录面板，程序还会把每次抽取实时追加一行到 data/history/YYYY-MM-DD.txt（按日期分文件）。每行格式为 [HH:MM:SS]：随机抽人：抽取数量3：张三、李四。该功能默认开启，可在「配置 → 基本设置 → 把抽取历史实时写入本地文件」中关闭，旁边提供「打开记录目录」按钮。注意：主界面抽取与悬浮球快速抽取都会写入。

菜单「日志」下提佛两个快捷入口：「打开今日历史记录」 直接打开当天的记录文件；「清除全部历史记录」（Ctrl+W）会同时清空右侧面板并删除 data/history 下的全部记录文件，操作前会弹窗确认。

Q: 抽取结果很多（超过 10 个）时会怎样？

为避免提醒窗口刷屏，当单次抽取超过 10 个（10 个及以内不省略）时：

  • 弹窗提醒与 ClassIsland 通知只显示前 10 个，其余以「其余 N 个已省略」提示；
  • 程序会强制将完整结果保存为 HTML，并写入历史记录文件（不受「自动保存抽取结果」开关影响）；
  • 随后再次弹窗提醒，并自动用系统默认程序打开该 HTML，以便查看完整结果。

Q: 名单文件很大、或者名字很长会怎样？

为避免超大文件造成卡顿，加载名单时程序会做以下限制，并在提示中说明：

  • 最多只读取文件的前 8MB；
  • 最多只读取 1000 个名字；
  • 每个名字自动去掉首尾空白，并截断到最多 20 个字符（随机点名另有更短的 10 字符限制）。

Q: 如何查看程序运行日志？

通过菜单「日志 → 查看日志」（Ctrl+L）打开当日日志文件。日志文件按日期滚动记录，存放在 data/log 目录。也可以通过「日志 → 清除日志」清理历史日志文件。

Q: 如何检查是否有新版本？

程序启动时会自动静默检测新版本（可在配置中关闭）。您也可以手动通过菜单「工具 → 检测更新」、主页的「更新」按钮，或更新程序本身来检查版本更新。版本号与版本代码的含义参见 版本号规则说明。

Q: 更新程序支持哪些下载方式？

更新程序（update.exe）支持 GitHub / Gitee 双更新源，检测到新版本后可直接下载安装包自动更新、前往官网下载，或使用夸克网盘 / 蓝奏云等备用网盘。勾选「接收测试版更新」后还能检查测试版。详见 更新与卸载工具说明。

Q: 随机点名和随机抽取有什么区别？

「随机抽取」会一次性给出指定数量的结果并记录到历史面板；「随机点名」则是跑马灯形式，名字快速跳动后由你点击「停止」定住某一个名字，更适合课堂提问、现场互动等场景。两者共用同一个样本库。详见 随机点名操作指南。

Q: 如何生成 RCP 编码文件？

自 V2.5.2 起，配套的「名单编码工具」已从套件中移除。日常使用可直接导入 .txt / .csv；如需 .rcp，可将明文名单按 Base64 编码后另存为 .rcp，或先导入样本库后在「配置 → 样本管理」中导出为 .rcp。详见 随机抽人操作指南。

Q: 如何卸载程序？

项目附带了独立的卸载工具 remove.exe，提供三种模式：

  • 保留数据：仅移除程序文件，保留配置、日志和结果数据
  • 重置配置：仅删除数据配置和日志，保留程序文件
  • 完全卸载：移除程序文件及所有用户数据

卸载时还会一并清理「开始菜单」中的程序组文件夹与桌面快捷方式。详情请参阅 更新与卸载工具说明。

Q: 关闭窗口后程序去哪了？怎么彻底退出？

如果开启了托盘（「配置 → 桌面集成 → 关闭窗口后保留系统托盘」，默认开启），点击窗口关闭按钮不会退出程序，而是隐藏到任务栏通知区继续运行。此时可以双击托盘图标或使用托盘菜单「显示主界面」唤回窗口，用托盘菜单「退出」完全退出。若取消了该选项，则任何退出操作都会完全退出程序。详见 桌面悬浮球与系统托盘。

Q: 桌面上的圆形悬浮按钮是什么？

那是可选的桌面悬浮球，用于快速抽取：左键单击执行当前预设的抽取操作（默认抽 1 个人），右键菜单分三个子菜单预设抽取模式（抽字母组 / 抽数字组 / 抽人）、抽取数量（1~9 个）与悬浮球大小，当前生效的项会带勾选标记；拖动可改变位置。不需要时可到「配置 → 桌面集成」取消钩选「显示桌面悬浮球」。详见 桌面悬浮球与系统托盘。

注意事项

  1. 重复名字处理：程序支持重复名字自动去重，可在配置中开启或关闭此功能。
  2. 抽取数量限制：抽取人数不能超过样本总数，程序会自动进行限制。
  3. 默认样本文件：样本库中的名单存放在 data/rcplist/ 目录，默认自动加载的样本可在「配置 → 基本设置 → 默认加载样本」中选择。
  4. 结果保存路径：结果文件默认保存在 data/result 目录或桌面，具体位置可在配置中设置。
  5. 跨平台支持：程序支持三大平台（Windows / Linux / macOS），但仅提供 Windows 编译版本。Linux 和 macOS 用户需自行通过源码运行。
  6. 优先支持 Windows：该项目优先支持 Windows 操作系统环境。对于 Linux 和 macOS 用户，可以使用，但可能会遇到一些未查明的问题。
  7. 合并重复名字：加载样本时，可自动合并重复的名字（可在配置中关闭）；随机点名加载名单时还会强制合并重复项。
  8. 名单文件编码：导入 .txt / .csv 名单时，程序会自动尝试多种文件编码（UTF-8 / GBK / GB2312 / GB18030 / UTF-16 等）解码。
  9. 名单读取上限：单个名单最多读取前 8MB、最多 1000 个名字，每个名字最多 20 个字符（随机点名 10 个字符）；超出的部分会被忽略并在提示中告知。
  10. 抽取历史记录文件：使用菜单「日志 → 清除全部历史记录」会连磁盘上的记录文件一起删除，如需保留请先备份 data/history 目录。
  11. 更新前先关闭程序：从安装包更新时，请先关闭「随机抽取工具套件」内的所有程序（主程序、更新程序等），否则可能因文件占用导致安装失败甚至数据损坏。
  12. 悬浮球与托盘的额外依赖：这两项功能依赖 pystray 与 Pillow。未安装时托盘不可用，程序会自动改为「关闭窗口即询问是否退出」；从源码运行时可通过 pip install -r requirements.txt 一并安装。
  13. 悬浮球始终置顶：悬浮球会显示在其他窗口之上，若不需要可在「配置 → 桌面集成」中关闭；也可在托盘菜单中快速切换显示 / 隐藏。
