下载须知

  1. 如果是从安装包更新随机抽取工具，请先关闭所有“随机抽取工具套件”内的程序（如：随机抽取工具主程序、更新程序等），然后再运行安装包进行安装，否则可能会导致致命性的错误（如程序文件完整性损坏、数据丢失等）
  2. 推荐使用程序内置的更新程序进行升级，它会自动检测新版本并完成下载安装，无需手动卸载重装。
  3. 如果使用Edge浏览器下载程序时，提示“通常不会下载xxx……”，请点击右边的三点，点击“保留”。如果出现弹窗进一步推荐你不要保留，请点击“删除”按钮旁边的倒三角，点击“仍然保留”。本程序完全开源，可承诺100%无病毒无恶意代码。
  4. 在Windows10及以上系统中，直接双击打开从互联网下载的exe文件会经过Windows Defender Smartscreen进行病毒扫描。由于本程序封装的安装包没有签名，可能会提示“未经信任的软件”，直接点击“更多信息”→“仍然运行”即可。

自行编译

如果您想自行编译源代码，请按照以下步骤操作：

  1. 确保安装了 Python 3.8+ 环境（官方发行版使用 Python 3.8.10 编译，以兼容 Windows 7）。
  2. 克隆或下载项目到本地：GitHub 或 Gitee。
  3. 安装 PyInstaller：pip install pyinstaller
  4. （仅限 Windows）在项目根目录运行构建脚本生成可执行文件：build.bat（目录式打包，依赖包外置于 _internal 目录）。
  5. （可选）使用 7z SFX Builder 搭配根目录下的 SFX_config.txt 打包自解压安装程序。

构建完成后会生成主程序 rctool.exe、更新程序 update.exe 与卸载工具 remove.exe。
