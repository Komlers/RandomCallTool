下载须知

  1. 如果是从安装包更新随机抽取工具，请先关闭所有“随机抽取工具套件”内的程序（如：随机抽取工具主程序、名单编码工具等），然后再运行安装包进行安装，否则可能会导致致命性的错误（如程序文件完整性损坏、数据丢失等）
  2. 如果使用Edge浏览器下载程序时，提示“通常不会下载xxx……”，请点击右边的三点，点击“保留”。如果出现弹窗进一步推荐你不要保留，请点击“删除”按钮旁边的倒三角，点击“仍然保留”。本程序完全开源，可承诺100%无病毒无恶意代码。
  3. 在Windows10及以上系统中，直接双击打开从互联网下载的exe文件会经过Windows Defender Smartscreen进行病毒扫描。由于本程序封装的安装包没有签名，可能会提示“未经信任的软件”，直接点击“更多信息”→“仍然运行”即可。

自行编译

如果您想自行编译源代码，请按照以下步骤操作：

  1. 确保安装了 Python 3.6+ 环境（推荐 3.8 及以上版本，建议 3.12）。
  2. 克隆或下载项目到本地：GitHub 或 Gitee。
  3. 安装 PyInstaller：pip install pyinstaller
  4. （仅限Windows）运行构建脚本生成可执行文件：build_standard.bat（标准打包）或 build_onefile.bat（单文件打包）。
