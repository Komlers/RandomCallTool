简介

随机抽取工具（RandomCallTool）是一个基于 Python3 + tkinter 的桌面应用程序，拥有 随机抽组、随机抽人、随机点名 三大核心功能。

主程序内置三档可切换的抽样模式（基本抽样 / 智能抽样 / 高级抽样），并支持样本库管理、历史记录、快捷键操作等丰富特性。

自 V2.7 起还提供 桌面悬浮球 与 系统托盘：桌面上点一下即可快速抽取，关闭窗口后也能继续后台运行。

项目还配套独立的 更新程序 与 卸载工具；更新程序支持 GitHub / Gitee 双更新源，并提供夸克网盘、蓝奏云等备用下载方式。

主要功能

🎲

随机抽组

支持从数字（1-26）或字母（A-Z）中随机抽取指定数量的组，操作简单直观。

👥

随机抽人

支持从样本文件（.rcp / .txt / .csv）或样本库中随机抽取指定数量的人名。

🎯

随机点名

跑马灯式点名，名字快速跳动后点击「停止」定格；支持自动点名与点名优化。

📊

三档抽样模式

基本抽样（内置）、智能抽样（智能降权）、高级抽样（自定义更公平），灵活应对不同场景。

⚖️

自定义权重

可为名单中的每个样本单独设置权重，权重越高被抽中的概率越大，抽取概率完全可控。

📚

样本库管理

可将常用名单导入样本库（上限 50 个），支持从样本库快速加载，方便日常使用。

📜

历史记录面板

右侧面板展示抽取历史，支持单条保存和批量保存全部历史为 HTML 文件。

⚙️

配置管理

多选项卡配置窗口，支持自动保存结果、抽样模式、样本管理、提醒方式、桌面集成、更新设置等丰富的自定义选项。

🔵

桌面悬浮球

桌面常驻一个置顶圆形按钮，左键一键快速抽取；右键分「抽取模式 / 抽取数量 / 悬浮球大小」三个子菜单预设，当前项带勾选，可随意拖动并记住位置。

🖥️

系统托盘

关闭窗口后可继续驻留系统托盘，也可配置为启动后直接后台运行；托盘菜单可快速显示主界面、打开配置或退出。

🔄

独立更新程序

支持 GitHub / Gitee 双更新源，可直接下载安装包，也可选择夸克网盘、蓝奏云等备用网盘。

🧹

卸载工具

三种卸载模式（保留数据 / 重置配置 / 完全卸载），并自动清理开始菜单与桌面快捷方式。

⌨️

快捷键操作

丰富的键盘快捷键支持，大幅提升操作效率，让抽取工作更加流畅。

📝

详细日志记录

按日期滚动记录程序运行状态，支持查看和清理日志文件，便于调试和追踪。

抽样模式

模式 0 · 基本抽样

基础

使用内置的 random.sample 进行简单随机抽取，每个样本被抽中的概率均等。适用于简单的抽选场景。

模式 1 · 智能抽样

智能

追踪近期抽取历史，自动降低刚被选中项的权重，让每个人都有更均等的机会被抽中。适用于多次连续抽取的场景。

模式 2 · 高级抽样

高级

利用高级算法，可自定义调整多种高级抽样方式，涵盖自定义权重、预抽取平衡、抽取前打乱等，可以使抽取更加公平
